# Fruit Matching Game 🍎🍌🍊🍉

A simple matching card game made while only using **HTML and CSS**.

This project was made way back in 2025 while learning the fundamentals of web development. It was for a performance task I had while I was in senior high school where I was tasked to develop a matching card game without using JavaScript in the code. At first it seemed impossible, but through sheer brainpower I managed to create what I would consider the most technical project I have ever made.

## Built With

* HTML
* CSS

## Notes

This project intentionally does **not** use JavaScript. I wanted to challenge myself to recreate the basic idea of a matching game using only what I had learned from HTML and CSS.

It isn't meant to be a fully-fledged game. It is mainly a project I created for school and my teachers way of making me think outside the box.
